# Green Haven

สร้างเว็บไซต์ชื่อ “TreeKingdom” สำหรับแสดงพรรณไม้หลายชนิด เช่น ไม้น้ำ ไม้ชื้น ไม้ดอก แคคตัส
1.โทนสีตามความเหมาะสมกับ  Logo ที่แนบ 2. ระบบสามารถแสงภาพต้นไม้ต่างๆพร้อมวิธีดูแลได้ 3.มีหน้า Home, Plants, Categories
3.1.Plants แบ่งต้นไม้เป็นหมวดๆพร้อมค้นหาได้ตามประเภทและกดเข้าไปดูหน้ารายละเอียดแต่ละต้นได้
3.2.Categories แบ่งเป็นอุปกรณ์ต่างๆ เช่นปุ๋ย, กระถาง, เครื่องมือและอุปกรณ์ และกดเข้าไปดูรายละเอียดได้ ในนั้นจะแสดงจำนวนคงเหลือ และราคาด้วย
4.ใช้ libในการเขียน ได้เต็มที่แต่อยากได้ animate เป็น GSAP
5.รองรับ mobile/tablet responsive 6.เปลี่ยนได้สองภาษา ไทยและอังกฤษ
8.ใช้ font น่ารัก 9.ไม่ต้องใช้ภาพจริงทำ hero
